# Security policy

This repository is a static badge library and does not accept or process credentials.

Do not place access tokens, account-wide API keys, or private project identifiers in layouts, examples, issues, or pull requests. UptimeRobot layouts should use only a monitor-specific read-only key intended for public status displays.

Report a suspected security issue privately through [GitHub's security advisory form](https://github.com/Nick2bad4u/github-badge-layouts/security/advisories/new).
